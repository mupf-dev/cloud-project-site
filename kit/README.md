# kit/ – Kopie des Design-Kerns (site-kit)

Nicht bearbeiten. Diese Dateien kommen aus dem Repo site-kit und werden mit dessen `sync.py`
aktualisiert; Änderungen hier gehen beim nächsten Abgleich verloren.

- `sitekit.py` – Generator (von `build.py` aufgerufen)
- `leakcheck.py` – Prüfung auf verbotene Inhalte (von `check-leaks.py` aufgerufen)
- `style.css`, `site.js` – Stylesheet-Kern und Skript, `theme.css` – Akzentfarben dieser Website
- `VERSION` – Stand von site-kit beim letzten Abgleich
